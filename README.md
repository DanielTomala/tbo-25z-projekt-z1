## Konfiguracja repozytorium
Repozytorium zostało skonfigurowane w taki sposób, aby zapewniać bezpieczne wytwarzanie oprogramowania poprzez ograniczenie uprawnień dla użytkowników oraz zablokowanie dodawania kodu bezpośrednio do głównej gałęzi _main_. Został utworzony odpowiedni "branch protection rule", dla brancha _main_, który wymaga utworzenie pull requesta przed wykonaniem merga, a także jego zatwierdzenia przez "code ownera". Ponadto branch _main_ została przełączona w tryb "read-only", aby uniemożliwić jego nieautoryzowaną zmianę.
